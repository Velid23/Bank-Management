# Bank-Management
This project is a functional Bank Management System developed in C++, mimicking core banking data operations such as client creation, lookup, dynamic tracking, updates, and conditional record removal. This application served as a vital practical stepping stone for mastering advanced file handling and persistent data storage in C++, as it implements custom string parsing algorithms to read and write token-delimited textual data (#//#) to and from an external file (Clients.txt). It also relies heavily on structured data handling, leveraging standard template library (STL) vectors to mirror flat-file database records dynamically in memory via custom User-Defined Data Types (Structs). The source file features two complete programming phases: my original prototype block (kept as a reference layout in comments) and the updated, structurally cleaner final version that integrates structured option handlers and memory optimization blocks influenced by my instructor's design. Evaluating both implementations inside a single environment provided an excellent practical exercise, allowing me to contrast procedural configurations, grasp error management patterns, mitigate text parsing issues, and solidify clean architecture principles.
